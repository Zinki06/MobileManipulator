# 정리된 시험 구역: 정적 지도 기반 주행

2026-09-05 사용자 요청: 지도 내부에서 정리 대상 이외의 물체를 치운 상태로 시험한다.

## 적용 범위

- `aruco_localizer/config/nav2_params.yaml`의 전역/지역 costmap 모두
  `static_layer + inflation_layer`만 사용한다.
- LiDAR/depth 장애물 레이어는 경로 계획과 경로 추종에서 제외한다.
  센서 관측의 잔상이 지도에 쌓여 불필요한 우회를 만드는 경로를 제거한다.
- 기존 `/map`의 벽, 장애물, 경계와 미지 영역 통과 금지는 유지한다.
- 지역 지도는 기존과 같이 odom 기준 rolling window이며, 정적 지도를 TF로 변환해 사용한다.
- 같은 Nav2를 사용하는 스테이션 이동과 물체 접근 모두 이 설정을 적용받는다.

이것은 모든 장애물을 무시하는 모드가 아니다. 실제 충돌 방지를 위해
LiDAR/depth → collision_monitor → motion_guard의 최종 정지 계층을 유지한다.
물체가 정지 영역에 있으면 우회하지 않고 멈출 수 있다. 센서가 끊겨도 멈춘다.
가구가 다시 놓이거나 사람이 들어오는 일반 환경의 자율 우회 운용에는 적합하지 않다.

## 남아 있는 별도 문제

- 목표 좌표만 Nav2에 주므로 마커 사이의 정확한 직선 추종을 강제하지는 않는다.
- 이전 로그에서 확인한 0.008 m/s 명령의 하드웨어 정수 절삭 문제는
  이번 지도 설정 변경으로 해결되지 않는다. 저속 정체가 다시 발생할 수 있다.
- 위치 보정 및 바퀴 보정 오차도 별도 검증 대상이다.

## 적용 및 확인

기존 브링업을 종료한 다음 다시 실행해야 한다. 명령은 변경하지 않았다.
시작 로그에서 전역/지역 costmap에 `static_layer`, `inflation_layer`가 나타나고
`Subscribed to Topics: scan depth_points`는 costmap에서 나오지 않아야 한다.
collision_monitor의 scan/depth 구독은 계속 유지된다.

검증: costmap 구성 회귀 테스트, 기존 Nav2 설정/경로 테스트 및
격리된 ROS 도메인의 실제 collision_monitor/guard 센서 단절·충돌 정지 테스트.
실물 로봇 주행은 자동으로 실행하지 않는다.
